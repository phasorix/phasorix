### Интегральная оценка деформации при печати модели: от точки к объёму

**Авторы:** Аксенченко А.А., Павлова Т.А. (научный руководитель)  
**Источник:** Перспективные материалы и технологии (ПМТ-2026): сборник докладов Национальной научно-технической конференции с международным участием. — М.: РТУ МИРЭА, 2026. — С. 606–611.  
**Конференция:** ПМТ-2026, Москва, 06–12 апреля 2026 г.  
**УДК:** 51-7:004.9 · **EDN:** CHEWFI · входит в РИНЦ  
**Ссылки:** [eLibrary](https://elibrary.ru/item.asp?id=91258557) · [PDF](2026_integral-deformation-3d-printing.pdf)

**Ключевые слова:** 3D-печать, деформация, усадка, ABS-пластик, интегральная оценка, математическое моделирование

Количественная оценка деформаций при FDM-печати полимерных изделий: интегральное суммирование внутренних напряжений послойно по высоте модели с использованием гипотезы плоских сечений Бернулли. Сравнены деформации образцов из ABS-пластика при разных температурных режимах и из PLA-пластика.
